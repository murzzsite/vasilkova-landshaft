## Папка images/
Создана для реальных фото объектов. Чтобы заменить плашки-заглушки на фото:
1. Положить файлы в `images/` (например `object-1.jpg`, `object-2.jpg`, `object-3.jpg`)
2. В `index.html` заменить `<div class="object__img object__img--1"></div>` на `<img class="object__img" src="images/object-1.jpg" alt="...">`
